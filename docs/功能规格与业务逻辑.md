# 功能规格与业务逻辑

本文档定义桌面便签挂件的业务规则与各功能模块的详细逻辑。

## 1. 顶部状态栏模块

### 1.1 下班倒计时与工时进度
- **配置项**：上班时间（默认 09:00）、下班时间（默认 18:00）。
- **计算规则**：
  - 上班时间前：显示“距上班还有 XX 小时”，进度为 0%。
  - 工作时间内：计算当前时间在总工时中的占比，动态绘制进度条，并倒计至下班。
  - 下班时间后：进度条显示 100%，文案切换为“已到下班时间，准时打卡撤退”。

### 1.2 发薪日倒计时
- **配置项**：每月发薪日期（1 日至 31 日，默认 15 日）。
- **计算规则**：
  - 当月发薪日未到：计算当天至发薪日天数，展示“距发薪 X 天”。
  - 当月发薪日当天：显示高亮文案“今日发薪日！💰”。
  - 当月发薪日已过：自动切换为计算次月发薪日的天数。

## 2. 待办事项模块

### 2.1 任务录入
- 支持在单行输入框中输入文字，按 Enter 键即刻创建。
- 支持直接粘贴多行文字，系统自动按换行符拆分成独立的待办条目。
- 提供 `[工作]`、`[生活]`、`[重要]`、`[学习]` 四个快速标签，点击可快速填入输入框。

### 2.2 任务交互
- **勾选操作**：点击复选框触发勾选，文本呈现删除线与灰色。
- **任务删除**：点击条目右侧删除图标移除任务。
- **一键清理**：提供“清理已完成”按钮，一键清空所有勾选项。

## 3. 多彩随手记便签模块

### 3.1 便签色彩系统
内置 5 款低饱和度柔和底色供随时切换：
- 暖阳杏黄（默认）：`#FFF9E6`
- 薄荷清绿：`#EDF8F2`
- 早樱柔粉：`#FDF2F4`
- 晴空淡蓝：`#EDF5FD`
- 极简冷白：`#F8F9FA`

### 3.2 内容编辑与防抖
- 支持多行无限制文本输入，打字时启动 400 ms 防抖定时器，输入停顿时自动写入 `data.json`。

## 4. 窗口形态与系统集成

### 4.1 桌面双形态
- **展开态**：尺寸 320 px × 520 px，展示完整挂件内容。
- **胶囊态**：高度折叠为 50 px，仅显示时间与待办数量。
- **折叠交互**：双击窗口顶部区域快速在展开态与胶囊态之间切换。

### 4.2 系统托盘与快捷键
- **任务栏隐藏**：挂件不占用 Windows 任务栏，常驻系统托盘区。
- **托盘菜单**：支持右键菜单快速显示挂件、隐藏挂件、打开设置与退出程序。
- **全局老板键**：注册 `Alt + Shift + H` 全局快捷键，一键隐藏或唤出挂件。

## 5. 外部独立配置与数据存储

系统采用外部独立文件持久化方案，直接保存在可执行文件同级目录：

### 5.1 配置文件（config.json）
存放基础设置，支持用户使用记事本直接修改：
- `WorkStartTime`（字符串）：上班时间，如 `"09:00"`。
- `WorkEndTime`（字符串）：下班时间，如 `"18:00"`。
- `Payday`（整数）：每月发薪日，范围 1 至 31。
- `AlwaysOnTop`（布尔值）：是否置顶。
- `Opacity`（浮点数）：窗口不透明度，范围 0.5 至 1.0。
- `SweetMessage`（字符串）：底部自定义留言。

### 5.2 数据文件（data.json）
存放业务数据：
- `Todos`（数组）：包含待办事项的 ID、内容、完成状态与创建时间戳。
- `Note`（对象）：包含随手记便签的正文、主题颜色与更新时间戳。
