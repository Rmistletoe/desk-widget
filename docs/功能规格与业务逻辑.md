# 功能规格与业务逻辑文档

本文档定义财务桌面便签挂件的业务规则与各功能模块的详细逻辑。

## 1. 顶部状态栏模块

### 1.1 下班倒计时与工时进度
- **配置项**：上班时间（默认 09:00）、下班时间（默认 18:00）。
- **计算规则**：
  - 上班时间前：显示“距离上班还剩 XX 小时”，进度为 0%。
  - 工作时间内：计算当前时间在总工时中的占比，动态绘制进度条；精确倒计至下班。
  - 下班时间后：进度条显示 100%，文案切换为“已到下班时间，准时打卡撤退”。

### 1.2 发薪日倒计时
- **配置项**：每月发薪日期（1 日至 31 日，默认 15 日）。
- **计算规则**：
  - 当月发薪日未到：倒计当天与发薪日差值，展示“距发薪 X 天”。
  - 当月发薪日当天：显示高亮状态文案“今日发薪日！💰”。
  - 当月发薪日已过：自动切换为计算距离次月发薪日的天数。

## 2. 待办事项模块 (Checklist)

### 2.1 任务录入
- 支持在单行输入框中输入文字，按 Enter 键即刻创建。
- 支持直接粘贴多行文字，系统自动按换行符拆分成独立的待办条目。

### 2.2 任务交互
- **勾选操作**：点击复选框即刻触发勾选，条目呈现删除线与淡灰色，0.3 秒后平滑移至列表末尾。
- **拖拽排序**：按住任务项可自由上下调整显示顺序。
- **一键清理**：提供清理已完成按钮，将所有勾选项归档隐藏，保持便签界面整洁。

## 3. 多彩随手记便签模块 (Sticky Note)

### 3.1 便签色彩系统
内置 5 款低饱和度柔和底色供随时切换：
1. **暖阳杏黄**（默认）：`#FFF9E6`
2. **薄荷清绿**：`#EDF8F2`
3. **早樱柔粉**：`#FDF2F4`
4. **晴空淡蓝**：`#EDF5FD`
5. **极简冷白**：`#F8F9FA`

### 3.2 常用模板快捷项
提供常用财务信息一键复制功能：
- 增值税发票抬头模板（名称、纳税人识别号、地址电话、开户行及账号）。
- 常用开票税率（13%、9%、6%、1%）。

## 6. 外部独立配置与数据存储规格

为实现“重新打包、更新版本或分发他人时不丢失用户配置”，系统采用外部独立文件持久化方案：

### 6.1 配置文件 (`config.json`)
存放于应用同级目录，以标准 JSON 格式明文呈现，支持用户直接使用记事本修改：
- `workStartTime`（字符串）：上班时间，如 `"09:00"`
- `workEndTime`（字符串）：下班时间，如 `"18:00"`
- `payday`（整数）：每月发薪日，`1` 至 `31`
- `alwaysOnTop`（布尔值）：是否总是置顶
- `opacity`（浮点数）：窗口不透明度，`0.6` 至 `1.0`
- `customMessage`（字符串）：底部自定义个性化/暖心提醒留言

### 6.2 数据文件 (`data.json`)
存放于应用同级目录：
- `todos`（数组）：包含待办事项的 ID、内容、完成状态、优先级（`normal`/`important`）与创建时间戳。
- `note`（对象）：包含随手记便签的正文、莫兰迪主题底色及更新时间戳。

### 6.3 读写生命周期
1. **启动时注入**：主进程在创建窗口前读取本地 `config.json` 与 `data.json`，在预加载层通过同步 IPC 注入 Vue 响应式 Store，首帧直出无白屏无跳动。
2. **变更时回写**：无论是界面弹窗修改配置，还是文字输入待办便签，Store 自动触发防抖落盘，实时同步写入外部文件。
3. **重新打包安全**：打包发布时，只要保留外部的 `config.json`，所有专属设置终身免重新配置。


### 5.2 老板键快速隐藏
- 支持全局快捷键（默认 `Alt + Shift + H`），一键隐藏至系统托盘，再次按下恢复显示。
