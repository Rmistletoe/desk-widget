# 系统架构与性能设计

本文档阐述财务桌面便签挂件的总体技术架构、核心模块设计与界面流畅度保障策略。

## 1. 架构总览

应用采用 Electron 主进程与 Web 渲染进程分层架构：

```text
┌────────────────────────────────────────────────────────┐
│                      Electron 主进程                    │
│  - 窗口管理（透明、无边框、置顶、阴影）                   │
│  - 系统托盘与上下文菜单                                │
│  - 全局快捷键注册（老板键、呼出便签）                    │
│  - 本地单实例锁（禁止多开）                             │
└───────────────────────────┬────────────────────────────┘
                            │ IPC 通信
┌───────────────────────────┴────────────────────────────┐
│                    Web 渲染进程 (Vue 3)                │
│  ┌───────────────────┐  ┌───────────────────────────┐  │
│  │     状态管理      │  │          核心视图         │  │
│  │  - TodoStore      │  │  - 状态胶囊 (TopBar)       │  │
│  │  - NoteStore      │  │  - 待办列表 (TodoList)     │  │
```

## 2. 界面流畅度保障策略

针对“界面必须流畅”的要求，采取以下具体技术方案：

### 2.1 渲染性能优化
- **CSS 硬件加速**：动画仅使用 `transform` 和 `opacity`，触发 GPU 合成层，避免触发布局回流（Reflow）与重绘（Repaint）。
- **零大型组件库**：不引入 Element Plus、Ant Design 等数百 KB 级别的通用组件库，界面元素采用轻量 CSS 自主实现，减少运行时虚拟 DOM 开销。
- **SVG 图标内联化**：所有系统图标采用轻量 SVG 单色矢量图形，无额外网络或字体文件加载。

### 2.2 数据持久化优化
- **内存优先读写**：渲染层操作响应（添加任务、勾选、文字键入）直接更新内存状态，视图 0 毫秒即时响应。
- **防抖持久化落盘**：对文本编辑应用 300 ms 防抖写入本地持久化，兼顾实时性与磁盘 I/O 开销，避免打字卡顿。

### 2.3 窗口形态与缩放动画
- **双形态尺寸变换**：
  - 展开态：宽度 300 px，高度 480 px，展示完整便签内容。
  - 胶囊态：宽度 240 px，高度 42 px，仅展示时间与待办数量。
- 窗口缩放过程通过透明通道平滑过渡，不出现白边或拉伸畸变。

### 2.4 冷启动与首屏毫秒级直出架构
针对桌面挂件“随开即见、不能卡顿等待”的要求，采取以下软硬件协同设计：
1. **网络零探针**：传入 `--no-proxy-server` 与 `--disable-background-networking`，彻底规避 Windows WPAD 代理探测与网络证书握手。
2. **GPU 着色器磁盘高速复用**：保留并利用 GPU Shader Cache 机制，DirectComposition Alpha 透明通道无需每次冷编译，极速渲染。
3. **消除 DWM 穿透握手阻塞**：无边框透明窗口设置 `hasShadow: false`，避免 Windows DWM 尝试计算无效的系统级阴影通道，纯由前端 Tailwind `shadow-xl` 提供硬件加速平滑阴影。
4. **禁止离屏高斯模糊黑洞**：移除透明窗口上无法穿透桌面的 CSS `backdrop-filter: blur(...)`，消除双通道离屏高斯卷积管道对 GPU 初始化的巨大消耗。
5. **解除后台降频挂起**：配置 `backgroundThrottling: false`，杜绝 `skipTaskbar: true` 的无边框挂件被操作系统节流降频（从原本可能延迟数秒降至 200~300ms 首屏直出）。
6. **单实例锁保障**：`app.requestSingleInstanceLock()` 自动守护，防止多开引起的 profile 锁竞争。
