# 财务桌面便签挂件 (Finance Desk Widget)

专为财务办公场景定制的轻量级桌面挂件工具。结合桌面便签、下班倒计时、发薪日提醒以及财务高频小工具，保持低干扰、低占用与即时保存。

## 功能概览

- **顶部状态胶囊**：实时显示下班倒计时、当日工时进度条、距离发薪日天数。
- **待办清单（Checklist）**：支持快速新建、勾选划线动效、拖拽排序、批量清理已办项。
- **多色随手记便签**：5 种低饱和度便签底色切换，支持常用信息（发票抬头、税号）快速复制。
- **财务专属小抽屉**：内置人民币金额转大写工具，输入即转并支持快捷复制。
- **桌面双形态**：支持卡片展开态与迷你胶囊态，支持边缘吸附与老板键快速隐藏。

## 技术选型

- **运行时**：Electron 30+
- **视图层**：Vue 3 + TypeScript + Vite
- **样式**：Tailwind CSS + 原生硬件加速过渡动效
- **存储**：本地持久化存储（Local Storage / JSON），输入实时防丢

## 核心设计指标

1. **冷启动时间**：小于 1 秒，无白屏加载。
2. **交互流畅度**：拖拽移动与任务勾选动画保持 60 fps。
3. **内存占用**：静默挂起状态内存占用控制在 60 MB 以内。
4. **数据安全**：所有按键与操作本地即时写入，无网络依赖，保护财务信息隐私。
