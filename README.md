# 桌面便签挂件 (Desk Widget)

基于 .NET 8 与 WPF 构建的原生轻量级桌面悬浮便签挂件。提供下班倒计时、工时动态进度、发薪日提醒、待办清单、多彩便签以及图形化设置。

## 功能特性

- **顶部状态胶囊**：实时显示下班倒计时、当日工时进度条与距离发薪日天数。
- **待办清单（Checklist）**：支持回车新建、多行拆分粘贴、打勾划线动效、分类标签速填与一键清理。
- **多彩随手记便签**：5 种莫兰迪低饱和度便签底色切换，打字实时防抖落盘。
- **图形化设置窗口**：点击齿轮图标自由调整作息时间、发薪日、窗口透明度与自定义暖心留言。
- **桌面双形态**：支持卡片展开态与迷你胶囊态，双击顶部区域快速折叠与展开。
- **系统托盘与老板键**：不占用任务栏，托盘右键退出，支持全局快捷键 `Alt + Shift + H` 快速隐藏与唤醒。
- **配置与数据独立持久化**：外部 `config.json` 与 `data.json` 直接持久化在可执行文件同级目录，重新打包不丢失配置。

## 目录结构

```text
desk-widget/
├── desk-widget.sln            # Visual Studio 解决方案文件
├── 测试快速启动.bat            # 调试运行快速启动脚本
├── 发布独立版.bat              # 单文件免安装绿色版打包脚本
├── docs/                      # 架构与规格文档（中文命名）
│   ├── 系统架构与性能设计.md
│   └── 功能规格与业务逻辑.md
└── src/                       # 应用源码
    └── DeskWidget/            # 原生 WPF 桌面工程
        ├── Converters/        # XAML 界面数据转换器
        ├── Models/            # 数据模型与配置实体
        ├── Services/          # 本地文件存储与 Win32 全局热键
        ├── ViewModels/        # MVVM 视图模型与业务逻辑
        ├── MainWindow.xaml    # 挂件主窗口布局
        └── DeskWidget.csproj  # 工程配置文件
```

## 技术选型

- **运行平台**：.NET 8.0 Windows
- **界面框架**：WPF（Windows Presentation Foundation）
- **UI 组件库**：WPF-UI 4.3.0
- **MVVM 库**：CommunityToolkit.Mvvm 8.4.2
- **数据持久化**：System.Text.Json
