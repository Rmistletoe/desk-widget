# 桌面便签挂件 (Desk Widget)

轻量级桌面悬浮便签挂件工具。结合桌面便签、待办清单、下班倒计时、工时进度、发薪日提醒以及图形化设置窗口，低内存占用、实时自动保存、支持系统托盘常驻。

## 功能概览

- **顶部状态胶囊**：实时显示下班倒计时、当日工时进度条、距离发薪日天数。
- **待办清单（Checklist）**：支持快速新建、多行拆分粘贴、勾选划线微动效与通用分类标签。
- **多彩随手记便签**：5 种低饱和度莫兰迪便签底色切换，打字实时保存不丢数据。
- **图形化设置窗口**：点击右上角 `⚙️` 自由调整上下班作息时间、发薪日、窗口透明度与自定义暖心留言。
- **桌面双形态**：支持卡片展开态与迷你胶囊态，双击快速折叠收起。
- **托盘常驻与老板键**：不占任务栏，托盘右键一键退出，支持全局老板键 `Alt + Shift + H` 快速隐藏与唤醒。

## 技术选型

- **运行时**：Electron 30+（内嵌 Chromium 与 Node.js 独立运行时，打包即用）
- **视图层**：Vue 3 + TypeScript + Vite
- **样式**：Tailwind CSS + 原生 GPU 硬件加速过渡动效
- **存储**：本地持久化存储（Local Storage / JSON），离线安全无外网依赖

## 核心设计指标

1. **冷启动时间**：小于 1 秒，无白屏加载。
2. **交互流畅度**：拖拽移动与任务勾选动画保持 60 fps。
3. **内存占用**：静默挂起状态内存占用控制在低水平。
4. **数据安全**：所有按键与操作本地即时写入，纯离线无网络上传。
